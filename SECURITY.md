# 🔒 Security Policy

## About This Project

Spin a Wheel is an open-source random wheel picker built with HTML, CSS, JavaScript, and Node.js.

We take the security of this project seriously and welcome responsible reports of potential vulnerabilities.

## Supported Versions

Security fixes are provided for the latest version of the project.

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes     |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

When reporting an issue, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Screenshots or proof of concept, if available.

Please avoid publicly disclosing security vulnerabilities before they have been reviewed.

You can contact the project maintainer through GitHub:

👉 https://github.com/RealTabbukhan

## Security Best Practices

When deploying this project:

- Keep Node.js and dependencies updated.
- Review third-party packages regularly.
- Never expose private credentials or API keys.
- Use secure server configurations.
- Validate and sanitize user input.
- Review changes before deploying them to production.
