# 🤝 Contributing to Spin a Wheel

Thank you for your interest in contributing to Spin a Wheel! 🎡

Spin a Wheel is a modern and customizable random wheel picker built with HTML5 Canvas, Vanilla JavaScript, CSS, and Node.js/Express.

We welcome bug reports, feature suggestions, documentation improvements, and code contributions.

## 🌟 How to Contribute

### 1. Fork the Repository

Create your own copy of the repository by clicking the **Fork** button on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/RealTabbukhan/spin-a-wheel.git
cd spin-a-wheel
```

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes

Improve the code, fix bugs, or add new features.

Please ensure your changes are clear, useful, and consistent with the existing project.

### 5. Test Your Changes

Install dependencies and run the application locally:

```bash
npm install
npm run dev
```

Check that the application works correctly before submitting your contribution.

### 6. Commit Your Changes

```bash
git add .
git commit -m "Add your feature"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Open a Pull Request

Go to your GitHub repository and open a pull request describing your changes.

## 🐛 Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Screenshots, if applicable.
- Browser and operating system details.

## 💡 Feature Requests

We welcome ideas that improve the wheel picker experience.

Please explain:

- What feature you would like to add.
- Why it would be useful.
- How you think it could work.

## 📜 Code Guidelines

- Keep the code clean and readable.
- Use meaningful variable and function names.
- Avoid unnecessary dependencies.
- Test your changes before submitting a pull request.
- Update documentation when necessary.
